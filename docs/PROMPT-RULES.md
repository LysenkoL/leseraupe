# Запрос к ИИ и сборка листа (актуально на 04.11.2026)

## Что можно получить при каком наборе букв

| Выбор | Результат |
|---|---|
| Одна A или только согласные | Материала нет: лист не создаётся, поздравления нет. Плашка называет букву, которая поможет. |
| M, A | Слоги и слова (Mama, am). Страница заполняется повторами. |
| M, L, A, O | Слоги и слова; плашка называет букву, с которой появятся предложения и истории. |
| M, L, S, A, O, I | Плюс короткие предложения и мини-сцены без T («Mia im Saal»). |
| Есть T | Истории от 6 предложений («Tom malt»), дальше весь запас. |

Минимума вроде «5 букв» нет: приложение проверяет конкретные слова и тексты, а не количество букв.

## Что идёт на лист

- **Истории:** длинные вперёд, мини-сцены (3–5 предложений, не меньше 2 вопросов) только когда длинных нет. Исходник: `src/data/quelle/geschichten.txt`, собирается через `npm run dict`.
- **Слова:** один блок «Wörter», короткие (am, im, und) примерно каждое четвёртое, распределены по блоку.
- **Предложения:** короткие без истории рядом идут в 2–3 столбца. Простые запасные («Ali las.») только когда обычных не хватает.
- **Свободное место на A4:** сначала новые слова (без имён), потом новые слоги, потом повторы по очереди. Одинаковое подряд не ставится. История не повторяется и не режется.

## Запрос к ИИ

В запросе: выученные буквы и сочетания, запрет на остальные, новая буква, верхние границы количества, требования к содержанию и JSON из полей `woerter`, `saetze`, `geschichte`, `fragen`. Старое поле `kleineWoerter` при чтении ещё принимается и попадает в слова.

**Словарь для ИИ открытый:** списка разрешённых слов в запросе нет. Значит, приложение проверяет буквы и фильтр содержания, но не смысл. Бессмыслицу из разрешённых букв («Mama malt Kakao») фильтр пропустит.

## Что делает приложение с ответом

1. Понимает JSON в кодовом блоке, с текстом вокруг, с экранированными скобками, двойным кодированием и лишней запятой.
2. Убирает всё с невыученными буквами, запрещённым содержанием, трудным произношением или словом через дефис.
3. **Незаметно добирает** слова и предложения до полного блока из того же словаря, что и для обычного листа. Имён при этом не больше двух.
4. История принимается только целиком. Если хоть одно предложение не прошло, берётся целая история из словаря или история не показывается.

**Родителю это не показывается** (правило 04.11.2026): на экране только то, с чем родитель может что-то сделать.

## Фильтр содержания (`src/core/content.ts`)

- Неподходящее: ругательства, оскорбления, взрослые и жестокие темы. Действует и на вопросы для родителей.
- Трудное произношение: Toast, Giraffe, Ballon, Vulkan и подобные. Действует только на текст для ребёнка.
- Проверяются целые слова и семейства слов, поэтому Wasser и Tasse проходят.
