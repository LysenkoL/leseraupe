# ТЗ: Leseraupe — генератор листов для чтения (1 класс)

Версия 27.10.2026 · утверждено, готово к разработке

## 1. Цель и сценарий

Leseraupe — PWA-приложение на телефоне (хостинг GitHub Pages, устанавливается на Android с иконкой, работает без адресной строки и без интернета). За минуту собирает лист A4 для чтения на немецком **только из уже изученных букв**, печатает его на Wi-Fi-принтер и засекает время чтения. Основа — школьная идея «Lesepass / Leseraupen»: 5 минут чтения в день, позже 10; за каждое полное чтение ребёнок получает «Perle» для своей гусеницы.

**Интерфейс и листы полностью на немецком** — приложением можно поделиться со школой и другими родителями. У каждого пользователя свои буквы, имя ребёнка и история — всё хранится только в его телефоне.

Обычный день:
1. Открыть приложение с иконки.
2. При необходимости отметить новую букву.
3. Выбрать 5 или 10 минут (и тему).
4. «Leseblatt erstellen» → предпросмотр. Не нравится → «Neu mischen».
5. «Drucken» → системный диалог печати Android → Wi-Fi-принтер (цветной).
6. Ребёнок читает, родитель жмёт «Timer» → сигнал через 5/10 минут.
7. После чтения родитель задаёт вопросы к истории (внизу листа).

## 2. Функции

### 2.1 Изученные буквы
- 43 кнопки в порядке расширенной **Schreibtabelle der Fibel** (порядок как во многих букварях; файлов-образцов в репозитории нет):
  `M L Ch B S D W Sch G · A E I O U · Au Ei Eu Ö Ü · -ie Ä -äu · N H R P Z T F J K · Sp St Pf Qu X V Y C · -ß -ng -ck -tz`
- Буквосочетания (Ch, Sch, Au, Ei, Eu, ie, äu, Sp, St, Pf, Qu, ß, ng, ck, tz) — отдельные «буквы». Пока сочетание не отмечено, слова с ним не используются, даже если отдельные буквы известны («Eis» нельзя, пока не пройдено Ei; «Sport» нельзя без Sp).
- Большая и маленькая буква — одно и то же (T = t).
- Пометка «neu»: последняя добавленная буква встречается на листе чаще других.
- Выбор букв запоминается. Обычно добавляется одна новая буква за раз; все прежние свободно используются.
- Стартовое состояние по умолчанию (пример): T O M L A I S (новая: S); каждый меняет под свой букварь.

### 2.2 Длительность
Переключатель **5 Min / 10 Min** — определяет объём листа (раздел 3) и время таймера.

### 2.3 Генерация — два способа
1. **Из словаря (по умолчанию).** Встроенный список простых немецких слов для 1 класса (~1500–2000 слов) + готовые короткие предложения и мини-истории. Берутся только те, что состоят из изученных букв. Офлайн, бесплатно.
2. **Через чат (без API).** «Prompt kopieren» кладёт в буфер готовый запрос (раздел 4). Кнопки «Claude öffnen» / «ChatGPT öffnen». Ответ вставляется в поле «Antwort einfügen» → приложение раскладывает его по листу.
**API-ключи не используются.**

### 2.4 Проверка букв
- Любое слово (из словаря или из чата) проверяется перед выводом: только изученные буквы и буквосочетания.
- Предложение с «чужой» буквой не попадает на лист. Под предпросмотром список: «Entfernt: Tisch (c, h)».
- Исключение — вопросы для родителей и имя ребёнка.

### 2.5 Предпросмотр и правки
- Лист показывается точно как при печати (уменьшенный A4, можно увеличить пальцами).
- «Neu mischen» — пересобрать весь лист; у каждого блока «↻» — пересобрать только его.
- Слово/предложение можно исправить вручную; после правки — снова проверка букв.

### 2.6 Печать
- «Drucken» → `window.print()` → системный диалог Android → Wi-Fi-принтер.
- Печатается только лист: без кнопок и меню, ровно 1 страница A4, поля ~1 см, цветная печать.
- Также «Als PDF speichern» (тот же диалог).

### 2.7 Timer
- Полноэкранный: крупные цифры 05:00 / 10:00, «Start / Pause / Neustart».
- Гусеница: каждую минуту у неё появляется новая «Perle» (кружок).
- Экран не гаснет (Wake Lock). В конце — мягкий звук, вибрация, надпись «Toll gelesen!».

### 2.8 Номера, история и журнал
- У каждого листа номер по порядку: Blatt 1, 2, 3… Номер присваивается при первой печати/сохранении, а не при каждом «Neu mischen».
- Статус листа: **erstellt → gedruckt → gelesen ✓**. «gelesen» ставится сам, когда таймер дошёл до конца, или кнопкой вручную. Один лист можно прочитать несколько раз — каждое чтение записывается.
- **Protokoll (журнал):** каждое событие с датой и временем — «Blatt 12 erstellt», «gedruckt», «gelesen, 5 Min», «Buchstabe E hinzugefügt».
- **Экран «Verlauf»:** сверху итоги — erstellt / gedruckt / gelesen / Minuten gesamt; ниже календарь месяца, дни с чтением закрашены, серия дней подряд; дальше список листов (новые сверху: номер, дата, тема, название истории, статус).
- Любой лист можно открыть и напечатать снова ровно таким же.
- Слова из истории учитываются, чтобы не повторяться (раздел 3).
- «Sicherung»: экспорт/импорт всей истории одним JSON-файлом (можно положить на Google Drive вручную).

### 2.9 Темы и квест
Тема меняет оформление листа: цвета, картинки по краям, костюм гусеницы. Гусеница есть всегда. Выбор на экране «Thema wählen» + переключатель «Jeden Tag ein anderes Thema (Zufall)».

| Тема | Гусеница | Украшения |
|---|---|---|
| Wiese | с цветком | цветы, бабочка, травка |
| Weltraum | в шлеме | звёзды, планета, ракета |
| Meer | маска с трубкой | рыбки, пузыри, волна |
| Zirkus | цилиндр | флажки, шарики |
| Zauberwald | корона | мухоморы, звёздочки |
| Winter | шапка с помпоном | снежинки, ёлка |

**Quest** — маленькое задание внизу листа (одно из списка, одобрено):
- **Finde!** — «Kreise alle Wörter mit S ein» (новая буква).
- **Zähle!** — «Wie oft steht Oma in der Geschichte?» + квадратик для ответа.
- **Male!** — «Male die Raupe an»: контурный рисунок по теме.
- **Geheimwort** — первые буквы подчёркнутых слов складываются в слово.

Кружок с номером листа внизу — как «Perle» школьной Leseraupe.

## 3. Состав листа и объём

Лист всегда помещается на 1 страницу A4 (ничего не обрезано!). 10 минут = больше текста и чуть меньше шрифт.

| Блок | Что внутри | 5 Min | 10 Min |
|---|---|---|---|
| Kopf | «Ich lese!», изученные буквы кружками, гусеница, Name (печатается сразу), Datum (пустая линия), Blatt-Nr. | да | да |
| 1. Silben | слоги из 2 букв | 18 | 24 |
| 2. Wörter | слова, сначала короткие | 20 | 30 |
| 3. Kleine Wörter | служебные (ist, im, am, so) | 8 | 8 |
| 4. Ähnliche Buchstaben (опц.) | пара, которую ребёнок путает (по умолч. l / I) | опц. | опц. |
| 5. Sätze | короткие предложения | 7 | 10 |
| 6. Geschichte | связная история с заголовком, 2–3 героя | 7 | 12 |
| Quest | см. 2.9 | 1 | 1 |
| Für Eltern | вопросы к истории | 3–4 | 4–5 |

Правила:
- **Никаких дефисов между слогами.**
- Слова не повторяются внутри листа и со словами двух предыдущих листов. Если слов не хватает — берутся те, что были давнее всего.
- Если слов мало, блок короче, место занимает крупнее шрифт — выдумки запрещены.
- Блоки включаются/выключаются перед генерацией.

## 4. Обмен с чатом

Шаблон промпта (подстановки в {} — из приложения):

```text
Du schreibst Lesetexte für ein Kind in der 1. Klasse (Deutschland).
Das Kind kennt NUR diese Buchstaben: {T, O, M, L, A, I, S}.
Neuester Buchstabe (bitte oft verwenden): {S}.
Bekannte Buchstabenverbindungen: {keine}.
Verwende KEINE anderen Buchstaben, auch nicht in Namen.
Groß- und Kleinschreibung ist erlaubt. Keine Silbentrennstriche.
Lesezeit: {5} Minuten.

Antworte NUR mit JSON in genau diesem Format:
{ "woerter": [{20} Wörter],
  "kleineWoerter": [{8} kurze Wörter],
  "saetze": [{7} kurze Sätze],
  "geschichte": { "titel": "...", "saetze": [{7} Sätze] },
  "fragen": [{3} Fragen an das Kind, normale Sprache] }
```

Приложение само находит JSON в ответе (даже с текстом вокруг или ```json), проверяет буквы (2.4) и раскладывает. Слоги и блок «Ähnliche Buchstaben» всегда генерирует само. Ошибка разбора → «Antwort konnte nicht gelesen werden. Bitte die ganze Antwort kopieren.»

## 5. Дизайн

Макеты: `docs/design/*.html` (открываются в браузере только как ориентир по разметке; там используются плейсхолдеры `/_blob/...` для шрифта — в проекте шрифт лежит в `public/fonts/`). Образцы листов: `Main.html`, `Blatt2.html`, `Blatt3.html`. Экраны: `App1-Start`, `App2-Vorschau`, `App3-Timer`, `App4-Historie`, `App5-Thema`. Верх листа по темам: `Themen-Kopf.html`.

### 5.1 Лист
- Блоки в скруглённых рамках, цвета и украшения — из темы. Номер блока в кружке.
- Текст для чтения всегда тёмный на белом. Цвет — только украшения.
- **Украшения никогда не заходят на текст и поля.** Рыбки, грибы, шарики, звёзды рисуются только в свободных зонах (поля листа, промежутки). Запрещённые зоны: «Ich lese!», кружки букв, строки Name и Datum (включая пустое место для даты), все блоки с текстом, квест. Реализация: у каждой темы фиксированные слоты украшений вне запрещённых зон; украшения под текстом (z-index); блоки и поля с белым непрозрачным фоном. Автотест: прямоугольники украшений не пересекаются с запрещёнными зонами ни в одной теме и ни в одном режиме (5/10 Min).

### 5.2 Экраны (всё на немецком)
1. **Start:** сетка 43 букв (gelernt — зелёные, neu — оранжевая, noch nicht — серые), Lesezeit 5/10, Thema, Blöcke, «Verlauf», большая кнопка «Leseblatt erstellen», «Mit Chat erstellen …».
2. **Vorschau:** лист A4 на всю ширину; внизу «Neu mischen», «Drucken», «Timer».
3. **Chat:** «Prompt kopieren», «Claude öffnen / ChatGPT öffnen», поле «Antwort einfügen».
4. **Timer**, 5. **Verlauf**, 6. **Thema wählen**.
7. **Einstellungen:** имя ребёнка (каждый вводит сам, по умолчанию пусто), пара похожих букв, Sicherung.
- Управление одной рукой, кнопки ≥ 44 px, главные кнопки внизу.

### 5.3 Шрифт — решение: **Inter, школьный вариант**
Эталон — Grundschrift, Schreibtabelle der Fibel (без файлов в репозитории): маленькая **l** с закруглением внизу, **I** — простая палочка, **a** однокруглая, **t** с хвостиком.
- Файлы: `public/fonts/Inter-Medium.woff2` (500), `Inter-SemiBold.woff2` (600), `Inter-ExtraBold.woff2` (800). Лицензия OFL (`Inter-LICENSE.txt`).
- Везде, где текст для чтения: `font-feature-settings: 'cv05' 1, 'cv11' 1;` (cv05 = l с закруглением, cv11 = однокруглая a).
- ВАЖНО: Inter с Google Fonts этих альтернатив не содержит — использовать только локальные файлы.
- Интерфейс — тоже Inter.
- Отклонены: Playwrite DE Grund (слишком тонкий), Andika (l и I не различить), Atkinson Hyperlegible (книжные a и g, I с перекладинами).

## 6. Техника

| Что | Решение |
|---|---|
| Стек | Vite + TypeScript (без тяжёлых фреймворков, допустим React) |
| PWA | manifest + service worker (vite-plugin-pwa); Android: Chrome → «App installieren» |
| Офлайн | словарь, шрифт, темы, иконки кэшируются; онлайн нужен только чат |
| Публикация | публичный репозиторий `leseraupe`, GitHub Actions собирает и выкладывает на Pages при push в main (`base` в vite.config = `/leseraupe/`) |
| Обновления | при запуске с интернетом подтягивается новая версия |
| Хранение | настройки — localStorage; история и журнал — IndexedDB |
| Sicherung | экспорт/импорт одним JSON-файлом |
| Словарь | JSON: слово, тип (Name / Nomen / Verb / kleines Wort), длина, тема + отдельный файл готовых предложений и мини-историй |
| Печать | `window.print()` + CSS `@page { size: A4; margin: 10mm }` |
| Timer | Screen Wake Lock API, звук Web Audio, `navigator.vibrate` |
| Тесты | Vitest: фильтр букв/буквосочетаний, разбор JSON из чата, неповтор слов, пересечение украшений с зонами |

Целевое устройство — Android + Chrome. Печать из установленного приложения на свой принтер проверяем первым делом.

## 7. Не входит в первую версию
- Графики и сложная статистика (итоги, календарь и журнал — входят, 2.8).
- Несколько детей, учётные записи, синхронизация с облаком.
- Озвучка, распознавание голоса, прописи.
- Google Play. Генерация по API-ключу.

## 8. Решения

| Вопрос | Решение |
|---|---|
| Телефон | Android |
| Буквы | запоминаются, добавляется по одной |
| Букварь | Grundschrift, порядок букв как во многих букварях |
| Путаемые буквы | пока l / I |
| Имя | вводится в настройках (по умолчанию пусто), печатается сразу |
| Повторы слов | не чаще, чем через день |
| API | не нужен |
| Название | Leseraupe |
| Язык | интерфейс и листы — немецкий |
| Шрифт | Inter, школьный вариант (cv05 + cv11) |
| Оформление | цветное, 6 тем, квест |
| История | нумерация, архив, журнал, итоги |

## 9. Критерии приёмки
- [ ] Установлена из Chrome на Android, открывается с иконки и в режиме полёта.
- [ ] Буквы T O M L A I S помнятся после перезапуска; новая добавляется одним нажатием.
- [ ] Лист на 5 и 10 минут — за 1–2 нажатия, без единой неизученной буквы (кроме вопросов для родителей и имени).
- [ ] Два листа подряд не совпадают по словам.
- [ ] Печать на цветной принтер: ровно 1 лист A4, ничего не обрезано, без кнопок.
- [ ] Шрифт как в Grundschrift (l с закруглением, I палочкой, однокруглая a).
- [ ] Украшения ни в одной теме не заходят на текст, Name и Datum.
- [ ] Режим чата: промпт копируется, ответ вставляется, лист собирается, чужие буквы отсеяны и показаны.
- [ ] Timer: экран не гаснет, в конце звук и вибрация, лист получает «gelesen ✓».
- [ ] Verlauf: любой лист печатается снова без изменений; итоги и календарь совпадают с журналом; Sicherung сохраняется и восстанавливается.
- [ ] Каждая тема печатается красиво, текст так же легко читается.
