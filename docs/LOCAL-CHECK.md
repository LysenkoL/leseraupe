## На компьютере

В папке `C:\Projekte\leseraupe`: `npm run dev`.
Открыть адрес, показанный терминалом (обычно http://localhost:5173/leseraupe/). Для текущей проверки используется http://127.0.0.1:5174/leseraupe/.
Это отдельная локальная версия; данные сайта и приложения из Google Play в неё автоматически не переносятся.

Проверить:
- Буквы на главном экране и в знакомстве: A–Z, затем дополнительные буквы и сочетания.
- Выбрать одну A: видна подсказка, создать пустой лист нельзя.
- Выбрать M и T: нет обещания слогов или истории, создание заблокировано.
- Выбрать M и A: доступны слоги и короткие слова, A4 заполнен ими с повторениями.
- Выбрать обычный набор из 7+ букв: доступны только реально получающиеся блоки.
- ИИ-чат: заново скопировать запрос, получить ответ и вставить его. Попробовать также старый проблемный ответ целиком.
- Старый пустой лист с одним дополнительным заданием не должен открывать поздравление в режиме чтения.
- Немецкий и украинский интерфейсы, печать в PDF: одна страница A4.

## Android

`npm run android` обновляет локальный Android-проект.
Сборка debug: Java из Android Studio, затем `android\gradlew.bat -p android assembleDebug`.
Иконка Android исправлена в adaptive XML: убран второй отступ поверх уже существующего в рисунке.
Её результат нужно проверить в Android, в браузере иконка запуска Android не отображается.

Debug-APK не заменяет версию из Google Play из-за другой подписи. Не удалять установленную версию с данными ради проверки без предварительной резервной копии.

## Дополнительная проверка качества ИИ-ответа

- Набор L, S, A, I: в новом запросе не должен предлагаться сырой список редких слов; идеи включают lila, Lisa и Ali.
- При отсутствии естественных предложений разрешён лист со слогами и словами с повторениями. Не требовать историю ради заполнения.
- Вставить старый ответ с Aas, Ass и множеством имён: Aas/Ass исключаются, из известных имён в списках остаётся максимум два.
- Один-два коротких служебных слова объединяются с обычными словами, если оба блока выбраны, и не растягиваются в отдельный блок.
- Дополнительное задание ИИ-листа не должно добавлять слова из другого словарного набора.
- Если предложение истории не прошло проверку, история и её вопросы не должны сохраняться в обрезанном виде.
- Связный сюжет, естественность фраз и пригодность нового ответа внешнего ИИ нужно оценить при ручной проверке. Автотесты проверяют обработку примеров, а не качество внешней модели.

## Единая предварительная проверка материала

- Проверить L, S, A, E, I: на старте доступны предложения, в запросе есть «Lisa las alles.», «Lisa las.», «Ali las alles.», «Ali las.».
- Запрос содержит закрытый разрешённый словарь, сформированный тем же checkText, которым проверяется вставка. Eis отсутствует без единицы Ei.
- Если ИИ вернул лишь слова, выбранные доступные предложения дополняются локальными проверенными примерами. Под листом явно указан источник дополнения.
- Если предложения выключены пользователем, дополнение не включает их обратно.
- Количество букв не является порогом: L, S, A, I допускают «Lisa las.», а M, A пока дают только слоги и слова.
- Отсутствие готовой истории в локальной библиотеке не означает невозможности сочинить её: ИИ может предложить собственную связную историю из разрешённого словаря.

Подробные правила и исключения: [PROMPT-RULES.md](PROMPT-RULES.md).

- На L S A E I предложения сохраняются, а свободная нижняя часть листа заполняется дополнительными строками слогов обычного размера.
- Без слогов повторяются выбранные слова; если выбраны только отдельные предложения, повторяются они. Истории не дублируются.

- Отсеянные ругательства не показываются повторно в предупреждении. Ручная правка проходит тот же фильтр содержания.
- После ручной правки сохранённого листа размер A4 проверяется заново. При простом открытии его прежний текст и масштаб сохраняются.
