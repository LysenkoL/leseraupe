## Блок A — основа (входит в первую публикацию)

### [x] A1. Профиль ребёнка в данных (подготовка) — готово 29.10.2026
**Зачем:** если позже добавить второго ребёнка, не придётся переносить историю у всех пользователей.
- Ввести сущность «Kind» (id, Name, gelernte Buchstaben, Einstellungen).
- Листы, журнал, Stolperwörter, перлы — привязаны к `kindId`.
- Сейчас всегда один профиль, экрана выбора НЕТ.
- Миграция существующих данных на телефоне (у владелицы уже есть история!) — без потерь.
**Готово, когда:** старая история после обновления на месте; тест миграции; Sicherung/Wiederherstellung работает с новым форматом.

### [x] A2. Знакомство при первом запуске (Onboarding) — готово 29.10.2026
**Зачем:** новый родитель должен за 1 минуту понять, что делать.
- 3–4 экрана, пролистываются, есть «Überspringen»:
  1. Что это: «Tägliche Leseblätter nur mit den Buchstaben, die dein Kind schon kennt.»
  2. **Приложение подстраивается под ребёнка:** сложность растёт, Stolperwörter возвращаются чаще (описать просто, 1–2 предложения).
  3. Отметить изученные буквы (та же сетка, что на Start).
  4. Имя ребёнка (необязательно) → «Los geht's».
- Показывается только при первом запуске; повторно — из «Über die App».
**Готово, когда:** чистая установка → онбординг; повторный запуск → сразу Start.

### [x] A3. «Über die App» — готово 29.10.2026 (Datenschutz-страница: `public/privacy.html`, ссылка в `DATENSCHUTZ_URL`)
- Экран из настроек: версия, кратко о приложении, **Datenschutz** (текст внутри + ссылка на страницу), контакт — адрес для связи из Play (один раз в коде: `KONTAKT` в `src/screens/ueber.ts`).
- Кнопка **«Feedback senden»** → открывает почту (mailto) с темой «Leseraupe Feedback» и версией приложения в тексте.
**Готово, когда:** всё открывается без интернета (кроме самой отправки письма).

### [x] A4. Без принтера: PDF и чтение с экрана — готово 29.10.2026 (в Android-версии «Teilen» переключить на Capacitor Share, см. PLAY.md)
**Зачем:** принтер есть не у всех семей.
1. **«Als PDF teilen»** в Vorschau: лист → PDF A4 → стандартное меню Android «Teilen» (WhatsApp, Telegram, E-Mail, Drive …). В браузере — Web Share API с файлом, иначе скачивание.
2. **Режим «Am Bildschirm lesen»:** лист по блокам на весь экран, крупный шрифт Inter (школьный вариант), листать свайпом/кнопками «Weiter», таймер виден сверху. Экран не гаснет.
**Готово, когда:** PDF совпадает с печатью 1:1; режим чтения удобен на телефоне и планшете.

### [x] A5. Больше готовых историй для первых букв — готово 29.10.2026 (19 новых: при T O M L A I S подходят 10, с +E 14, +N 17, +R 19, +U 21)
**Зачем:** при 6–8 буквах сейчас подходят только 2 из 24 готовых историй.
- Добавить 15–20 историй в `src/data/quelle/geschichten.txt` для маленьких наборов букв (типичные первые буквы: M A I L O S T E N R U).
- Каждая: заголовок, 6–8 предложений, 2–3 вопроса для родителей. Естественный немецкий, без дефисов.
- `npm run dict`, тест: при T O M L A I S подходит ≥ 8 готовых историй.

### [x] A6. Несколько листов сразу + своё время таймера — готово 29.10.2026
**Зачем:** родитель может сразу сделать несколько листов (например на неделю), а время чтения выбирает отдельно — ребёнок не всегда успевает один лист за 5 минут.
- Один размер листа (как бывший «5 Min»); плотный лист «10 Min» убрать. Старые листы в истории не меняются.
- Блок «Klein l oder groß I?» убрать совсем — трудные буквы/слова родитель отмечает через Stolperwörter (B2).
- На Start вместо «5/10 Minuten» — «Blätter: − 1 +» (1–5). Листы серии получают номера по порядку, без повторов слов между ними; сложность растёт сама через B1.
- Серия печатается одним заданием и одним PDF: листы по порядку, каждый ровно на своей странице A4, без разрывов.
- Таймер отдельно от листов: время выбирается на экране таймера (5/10/15/20 и −/+ шагом 5 мин), последнее значение запоминается. «gelesen» получает лист, с которого запущен таймер, с фактическими минутами.
**Готово, когда:** 4 листа → один PDF из 4 страниц A4 и одна печать; тест на неповтор слов между листами; таймер на любое время.

## Блок B — развитие (тоже входит в первую публикацию)

### [x] B1. Рост сложности внутри одной буквы — готово 29.10.2026 (Stufe 1–5, таблица `STUFEN` в `src/core/generator.ts`)
- Считать номер листа с момента добавления последней буквы: Blatt 1 → проще, 2 → чуть сложнее … Новая буква → снова с уровня 1.
- Уровень влияет на: длину слов, долю двусложных слов, длину предложений, длину истории.
- Показывать уровень родителю мелко в Vorschau («Stufe 2»).
**Готово, когда:** тесты: уровень 1 в среднем короче уровня 3; при новой букве уровень сбрасывается.

### [x] B2. Stolperwörter — готово 29.10.2026
- После чтения (после таймера или кнопкой «Gelesen») — **необязательный** шаг: «Wo hat dein Kind gestockt?» — родитель тапает слова на листе.
- Отмеченные слова чаще появляются на следующих листах (но не на каждом).
- **Снятие отметки — только вручную** (изменено 29.10.2026: программа не слышит чтение и не может знать, что слово прочитано без запинки):
  - в настройках у каждого слова «Kann es ✓» (засчитывается как «побеждено») и ✕ (просто убрать, например ошибочную отметку), плюс «Alle löschen»;
  - если слово 3 раза подряд было на листе и родитель его не отметил — только подсказка «vielleicht schon sicher?», слово остаётся.
- В Verlauf: сколько Stolperwörter «побеждено» (= отмечено «Kann es ✓»).
**Готово, когда:** тесты на частоту появления; слово само не исчезает; данные привязаны к профилю ребёнка (A1).

### [x] B3. Цветные слоги — готово 29.10.2026 (правила в `src/core/silben.ts`, исключения в `src/data/quelle/silben-ausnahmen.txt` — если слово разбито неверно, вписать его туда и `npm run dict`)
- Переключатель «Silben farbig» (по умолчанию выкл.).
- Слоги **чередуются цветом** (синий/красный, как в книгах для Erstleser), **без дефисов и пробелов**.
- Разбивка на слоги хранится в словаре (поле `silben`), для шаблонных предложений — по словам.
- Цвета контрастные и при ч/б печати различимы по оттенку серого.
**Готово, когда:** все слова словаря имеют разбивку; тест «нет дефисов»; печать и PDF корректны.

### [x] B4. Цифровая Leseraupe и грамота — готово 29.10.2026
- На Start/Verlauf гусеница: за каждый прочитанный лист — новая перла.
- После 10 перл — «Urkunde» для печати/PDF (имя ребёнка, дата, количество листов); затем новая гусеница.
**Готово, когда:** перлы считаются из журнала (не отдельным счётчиком).

### [ ] B5. Напоминание «Lesezeit!» (только Android-версия — делать ПОСЛЕ упаковки Capacitor)
- В настройках: выкл. по умолчанию; время на выбор; дни недели.
- Локальное уведомление (Capacitor Local Notifications), без сервера.
**Готово, когда:** работает после перезагрузки телефона; можно выключить.

### [x] B6. Язык интерфейса DE / UK — готово 29.10.2026 (тексты в `src/i18n/de.json` и `uk.json`)
- Выбор в настройках; по умолчанию — язык телефона (если не украинский — немецкий).
- Переводится только интерфейс. **Листы для чтения всегда на немецком.**
- Тексты в файлах переводов (`de.json`, `uk.json`), без строк в коде.
**Готово, когда:** все экраны переведены; тест, что листы не меняются от языка.
